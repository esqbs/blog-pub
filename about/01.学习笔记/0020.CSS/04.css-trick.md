## 滚动条样式

```css
::-webkit-scrollbar {
  width: 8px;
  background: white;
}
::-webkit-scrollbar-corner, /* 滚动条角落 */
::-webkit-scrollbar-thumb,
::-webkit-scrollbar-track {
  border-radius: 4px;
}
::-webkit-scrollbar-corner,
::-webkit-scrollbar-track {
  /* 滚动条轨道 */
  background-color: rgba(180, 160, 120, 0.1);
  box-shadow: inset 0 0 1px rgba(180, 160, 120, 0.5);
}
::-webkit-scrollbar-thumb {
  /* 滚动条手柄 */
  background-color: #00adb5;
}
```

## 文本溢出隐藏

https://css-tricks.com/line-clampin/

```css
// 单行文本溢出隐藏
.ellipsis {
	white-space: nowrap;
	text-overflow: ellipsis;
	overflow: hidden;
}

// 多行文本溢出
.multiple-ellipsis {
	display: -webkit-box;
	-webkit-line-clamp: 3;
	-webkit-box-orient: vertical;
	overflow: hidden;
}

// 另一种多行文本溢出
html { 
	--lh: 1.4rem;
	line-height: var(--lh);
}
.truncate-overflow { 
	--max-lines: 3;
	position: relative;
	max-height: calc(var(--lh) * var(--max-lines));
	overflow: hidden; padding-right: 1rem; /* space for ellipsis */
} 
.truncate-overflow::before { 
	position: absolute;
	content: "...";
	inset-block-end: 0; /* "bottom" */
	inset-inline-end: 0; /* "right" */
} 
.truncate-overflow::after { 
	content: "";
	position: absolute;
	inset-inline-end: 0; /* "right" */
	width: 1rem;
	height: 1rem;
	background: white;
}

```
