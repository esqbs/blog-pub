# shell脚本

## 基础脚本

### 创建脚本

```bash
$ touch my_shell.sh
$ chmod u+x my_shell.sh
$ vim my_shell.sh
#!/bin/bash
#this is a test shell
date
who
$ ./my_shell.sh
```

### 显示消息

`echo`命令可用单引号或双引号来划定字符串

`-n` 字符串和命令输出显示在同一行

```bash
$ cat ./my_shell.sh
#!/bin/bash
#this is a test shell
echo -n "The time and date are:"
date
echo "Let's see who's logged into the system:"
who
```

### 使用变量

#### 使用环境变量


#### 使用自定义变量

* 字母、数字或下划线组成的字符串
* 长度不能超过20个字符
* 区分大小写

```bash
$ cat ./my_shell.sh
#!/bin/bash
days=10

```

### 命令替换

```bash
$ cat ./my_shell.sh
#!/bin/bash
today=$(date +%y%m%d)
ls /usr/bin -al > log.$today
```

> 命令替换会创建出子shell来运行指定命令，这是由运行脚本的shell所生成的一个独立的shell。因此，在子shell中运行的命令无法使用脚本中的变量


### 管道

> Linux系统会同时运行这两个命令，在系统内部将二者连接起来。当第一个命令产生输出时，它会被立即传给第二个命令。数据传输不会用到任何中间文件或缓冲区

```bash
$ ls | sort | more
```

### 数学运算

> bash shell的数学运算符只支持整数运算

```bash
$ cat ./my_shell.sh 
#!/bin/bash
var1=100
var2=50
var3=$[$var1 + $var2]
echo The result is $var3
```

| 运算符                   | 描述                                                 |
| ------------------------ | ---------------------------------------------------- |
| ARG1 \| ARG2             | 如果ARG1既不为null也不为0，就返回ARG1；否则返回ARG2  |
| ARG1 & ARG2              | 如果ARG1和ARG2都不为null或0，就返回ARG1；否则返回0   |
| ARG1 < ARG2              | 如果ARG1小于ARG2，就返回1；否则返回0                 |
| ARG1 <= ARG2             | 如果ARG1小于或等于ARG2，就返回1；否则返回0           |
| ARG1 = ARG2              | 如果ARG1等于ARG2，就返回1；否则返回0                 |
| ARG1 != ARG2             | 如果ARG1不等于ARG2，就返回1；否则返回0               |
| ARG1 >= ARG2             | 如果ARG1大于或等于ARG2，就返回1；否则返回0           |
| ARG1 > ARG2              | 如果ARG1大于ARG2，就返回1；否则返回0                 |
| ARG1 + ARG2              | 和                                                   |
| ARG1 - ARG2              | 差                                                   |
| ARG1 * ARG2              | 积                                                   |
| ARG1 / ARG2              | 商                                                   |
| ARG1 % ARG2              | 余数                                                 |
| STRING : REGEXP          | 如果REGEXP模式匹配STRING，就返回该匹配模式的内容     |
| match STRING REGEXP      | 如果REGEXP模式匹配STRING，就返回该匹配模式的内容     |
| substr STRING POS LENGTH | 返回起始位置为POS（从1开始计数）、长度为LENGTH的子串 |
| index STRING CHARS       | 返回CHARS在字符串STIRNG中所处的位置，否则返回0       |
| length STRING            | 返回字符串STRING的长度                               |
| + TOKEN                  | 将TOKEN解释成字符串，即使TOKEN属于关键字             |
| (EXPRESSION)             | 返回EXPRESSION的值                                   |

### 退出脚本

* Linux提供了专门的变量$?来保存最后一个已执行命令的退出状态码
* `exit`命令允许在脚本结束时指定一个退出状态码

| 状态码  | 描述                       |
| ------- | -------------------------- |
| 0       | 命令成功结束               |
| 1       | 一般性未知错误             |
| 2       | 不适合的shell命令          |
| 126     | 命令无法执行               |
| 127     | 没有找到命令               |
| 128     | 无效的退出参数             |
| 128 + x | 与Linux信号x相关的严重错误 |
| 130     | 通过Ctrl+C终止的命令       |
| 255     | 正常范围之外的退出状态码   |

## 结构化命令

### if-then语句

* bash shell的`if`语句会运行`if`之后的命令。如果该命令的退出状态码为0，那么位于then部分的命令就会被执行
* `test`命令可以在`if-then`语句中测试不同的条件。如果`test`命令中列出的条件成立，那么`test`命令就会退出并返回退出状态码0
* 如果不写`test`命令的condition部分，则它会以非0的退出状态码退出并执行`else`代码块语句

```bash
$ cat ./my_shell.sh 
#!/bin/bash
var=""
# 可以写成 if [ $var ]
if test $var
then
echo "The var variable has content and returns a True"
else
echo "The var variable has doesn't hava content"
fi
```

#### test 数值比较

```bash
$ cat ./my_shell.sh 
#!/bin/bash
var=6
# 比较运算符 eq ge gt le lt ne
if [ $var -lt 10 ]
then
echo "The var variable has content and returns a True"
else
echo "The var variable has doesn't hava content"
fi

```

#### test 字符串比较

```bash
$ cat ./my_shell.sh 
#!/bin/bash
var=Str
if [ $var \> str ]
then
echo "The var variable has content and returns a True"
else
echo "The var variable has doesn't hava content"
fi
```

* 比较运算符` = != < > -n -z`
* 大于和小于需要转义，`\> \<`
* `-n str` 检查str的长度是否不为0；`-z str` 检查str的长度是否为0
* 大于和小于使用的是标准的Unicode顺序。`sort`命令使用的是系统的语言环境设置中定义的排序顺序。对于英语，语言环境设置指定了在排序顺序中小写字母出现在大写字母之前
* 空变量和未初始化的变量会对shell脚本测试造成灾难性的影响。如果不确定变量的内容，那么最好在将其用于数值或字符串比较之前先通过`-n`或`-z`来测试一下变量是否为空

## 用户输入

### 传递参数

```bash 
$ cat ./my_shell.sh 
#!/bin/bash
sh_name=$( basename $0 )
echo This script name is $sh_name
echo The first parameter is $1
echo The second parameter is $2
echo The number of parameters is $#
echo The last parameter is ${!#}
echo The paramters is $*
echo The paramters are $@
```

* `$#`含有脚本运行时携带的命令行参数的个数，`${!#}`返回最后一个参数
* 当命令行中没有任何参数时，`$#`的值即为0，但`${!#}`会返回命令行中的脚本名
* `$*`变量会将所有参数视为单个参数，而`$@`变量会单独处理每个参数
* 如果脚本需要的命令行参数不止9个，在第9个位置变量之后，必须在变量名两侧加上花括号，比如`${10}`

### 移动参数

在使用`shift`命令时，默认情况下会将每个位置的变量值都向左移动一个位置，变量`$0`的值不会改变；

`shift n` 会将每个位置的变量值都向左移动n个位置

```bash
$ cat ./my_shell.sh 
#!/bin/bash
count=1
while [ -n "$1" ]
do
	echo "Parameter #$count = $1"
	count=$[ $count + 1]
	shift
done
exit

$ ./my_shell.sh "111" "222" "333"
Parameter #1 = 111
Parameter #2 = 222
Parameter #3 = 333
```

### 处理参数

```bash
$ cat ./my_shell.sh 
#!/bin/bash
set -- $(getopt -q ab:cd "$@")
while [ -n "$1" ]
do
	case "$1" in 
		-a) echo "Found the -a option";;
		-b) echo "Found the -b option with parameter value $2"
			shift;;
		-c) echo "Found the -c option";;
		--) shift
			break;;
		*) echo "$1 is not option";;
	esac
	shift
done

echo
count=1
for param in "$@"
do
	echo "Paramter #$count:$param"
	count=$[ $count + 1 ]
done
exit

$ ./my_shell.sh -a -b 12 -c -- 11 22 33
Found the -a option
Found the -b option with parameter value '12'
Found the -c option

Paramter #1:'11'
Paramter #2:'22'
Paramter #3:'33'
```

* `set`命令有一个选项是双连字符（--），可以将位置变量的值替换成`set`命令所指定的值
* `getopt`命令：在每个需要参数值的选项字母后面加一个冒号；
* `getopt`命令：未包含指定选项，默认情况下，会产生一条错误消息，-q 忽略错误消息
* `getopt`命令并不能处理带空格和引号的参数值，`getopts` 可以

```bash
$ cat ./my_shell.sh 
#!/bin/bash
while getopts :ab:cd opt
do
	case "$opt" in 
		a) echo "Found the -a option";;
		b) echo "Found the -b option with parameter value $OPTARG";;
		c) echo "Found the -c option";;
		*) echo "$opt is not option";;
	esac
done

shift $[ $OPTIND - 1 ]

echo
count=1
for param in "$@"
do
	echo "Paramter #$count:$param"
	count=$[ $count + 1 ]
done
exit

$ ./my_shell.sh -a -b 12 -c 11 22 33
Found the -a option
Found the -b option with parameter value 12
Found the -c option

Paramter #1:11
Paramter #2:22
Paramter #3:33

```

* OPTARG环境变量保存参数值；OPTIND环境变量保存正在处理的参数位置

## 数据输出

> * Linux系统会将每个对象当作文件来处理，包括输入和输出。Linux用文件描述符来标识每个文件对象。文件描述符是一个非负整数，唯一会标识的是会话中打开的文件
> * bash shell保留了前3个文件描述符（0 STDIN、1 STDOUT和2 STDERR）
> * 输入重定向符（<），重定向指定的文件替换标准输入文件描述符
> * 输出重定向符（>），将所有输出重定向到指定的文件；（>>） 将数据追加到某个文件
> * 默认情况下，STDERR和STDOUT指向同一个地方

### 命令行中重定向

```bash
$ ls 1> stdout.txt #重定向正常输出
$ ls 2> stderr.txt #重定向错误消息
$ ls &> std.txt #重定向正常输出和错误消息
```

### 脚本中重定向

```bash
$ cat ./my_shell.sh 
#!/bin/bash
# 临时重定向
echo "This is an error message" >&2

# 永久重定向
exec 2>err.txt
echo "This is an error message" >&2

# 重定向输入
exec 0<input.txt
count=1
while read line
do
	echo "Line $count: $line"
	count=$[ $count + 1 ]
done

# 创建输出重定向
exec 3>test3.txt
echo "This should be stored in the test3.txt" >&3

# 重定向然后恢复
exec 3>&1
```

**cron语法格式**

```js
# m   h   dom   mon dow  command
0-59 0-23 1-31 1-12 0-7  command
```

| 符号    | 含义                   | 取值范围 |
| ------- | ---------------------- | -------- |
| m       | 表示分钟               | 0-59     |
| h       | 表示小时               | 0-23     |
| dom     | day of month，表示日期 | 1-31     |
| mon     | month，表示月份        | 1-12     |
| dow     | day of week，表示星期  | 0-7      |
| command | 待执行的命令           | -        |

需要特殊说明的是，dow 的取值范围为 `0-7` 共 8 个数，`1-6` 分别表示周一-周六，0 和 7 均表示`周日`

另外需要使用一些特殊符号实现灵活的配置：

- `* 代表所有值`
- `/ 代表“每”`
- `- 代表范围`
- `, 分割数字`

```bash
## 指定具体执行时间
2   *  *  *  * ls    #每个小时的第 2 分钟执行一次 ls 命令
30  7  *  *  * ls    #每天 7：30 执行一次 ls 命令
30 20  *  *  2 ls    #每周二，20：30执行一次 ls 命令（0 和 7 表示星期天）

## 指定间隔时间
*/2 *  *  *  * ls    #每隔 2 分钟执行一次 ls 命令

## 指定时间段
30  7 3-6 *  * ls    #每个月的 3，4，5，6 号的 7：30 分各执行一次 ls 命令

## 指定多个时间
30  7 3,6 *  * ls    #每月的 3 号和 6 号的 7：30 分各执行一次 ls 命令
```

### 在函数中使用变量

```bash
$ cat my_shell.sh

	local temp=$[ $value + 5 ] # local 修饰局部变量

}
```

### 在函数中使用数组

> 函数中传入数组或返回数组时都需要将数组展开

```bash
$ cat my_shell.sh 
#!/bin/bash
function arrayhandler {
	local origarray
	local newarray
	local elements
	local i
	origarray=($(echo "$@"))
	newarray=($(echo "$@"))
	elements=$[ $# -1 ]
	for(( i=0; i <= $elements; i++ ))
    {
    	newarray[$i]=$[ ${origarray[$i]} + 2 ]
    }
    echo ${newarray[*]}
}

myarray=(1 2 3)
echo "The original array is ${myarray[*]}"
arg1=$(echo ${myarray[*]})
result=($(arrayhandler $arg1))
echo "The result is ${result[*]}"

```
